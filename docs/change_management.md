# Change management

| Stakeholder | What changes | Concern | Plan |
|---|---|---|---|
| Teachers | Form optional for same-batch; WhatsApp reminders | "More alerts", loss of control | Pilot cohort first; one reminder, one escalation; show 'no action needed' confirmations |
| Ops executives | From approving every row to working exceptions | Job role / blame for errors | Reframe as exception owners; weekly false-positive review led by them |
| Finance | Gateway is source of truth | Reconciliation trust | Shadow report comparing engine vs their ledger |
| Parents | Faster confirmations; fewer duplicate asks | Messaging errors | Human-approved templates initially; registered number only |
| Head of Ops | Owns thresholds and the auto-approve flag | Wrong auto-approval risk | Kill-switch, audit trail, 0-error go/no-go gates |

Principles: shadow before live; one cohort at a time; every automated message reversible by a human; publish weekly metrics (including failures); train with the real exception examples from this audit (84904, 84907, 84909, 84911, 84913).
