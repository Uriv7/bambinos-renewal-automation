# Teacher follow-up prompt (wording polish)
**System:** Rewrite the WhatsApp draft for an educator. Tone: polite, brief (<= 45 words), one clear action. Keep every fact and the invoice number exactly. Do NOT add amounts, gateway ids, parent details or deadlines that are not in the draft. Return only the message.
Purposes: TEACHER_FORM_REMINDER (submit missing form), TEACHER_FORM_CORRECTION (invoice reference wrong - resubmit), TEACHER_AMOUNT_CHECK (amount on form differs from payment).
